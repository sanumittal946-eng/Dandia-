# Rang De Nights

Create a premium, viral, Gen-Z focused Navratri 2026 music and event website for an Indian audience.

The website should NOT look like a traditional festival/event website. It should feel like a modern music brand, combining the energy of Navratri, Garba, Dandiya, live DJ culture, Indian street aesthetics and modern Gen-Z web design.

BRAND DIRECTION

Theme:

Navratri 2026

Garba

Dandiya

Music

Dance

Youth/Gen-Z

Indian festive energy

Visual style:

Dark premium background

Vibrant red, orange, pink, purple and electric yellow accents

Neon gradients

High contrast typography

Large bold display typography

Grain/noise texture

Indian decorative patterns used subtly

Glowing lights

Festival photography

Dynamic motion

Premium music-event aesthetic

The website should feel like a combination of:

Modern music festival website

Indian cultural festival

Gen-Z nightlife website

Viral Instagram/Reels aesthetic

Do not make it look like a generic Bootstrap event template.

Write clean, reusable and production-ready components.

MOBILE EXPERIENCE

The website must be designed mobile-first.

On mobile:

Hero should be 100vh

Large typography

Sticky bottom "GET PASSES" button

Swipeable event cards

Horizontal scrolling music cards

Vertical social/reels feed

Touch-friendly buttons

Make sure no content overflows horizontally.

SEO

Add:

Proper title

Meta description

Open Graph metadata

Twitter/X card metadata

Semantic HTML

Proper heading hierarchy

Image alt text

Suggested title:

"Navratri 2026 | Jaipur's Biggest Garba & Dandiya Experience"

Suggested description:

"Experience Navratri 2026 with Garba, Dandiya, live DJs, music, lights, food and unforgettable nights in Jaipur."

PERFORMANCE

Optimize:

Lazy-load images

Compress images

Avoid unnecessary animations on mobile

Use CSS transforms for animations

Avoid excessive JavaScript

Keep Lighthouse performance high

IMPORTANT

Use realistic placeholder content and high-quality placeholder imagery initially.

Keep all event information, prices, dates, artists, venue and booking URLs in a single configuration/data file so they can easily be changed later.

Create reusable components rather than putting everything into one file.

The final website should feel like a real commercial festival website ready to launch, not a student project.

Most importantly:

MAKE IT LOOK VIRAL.

The first 5 seconds of the website should make a visitor think:

"WHAT IS THIS? 🔥"

and immediately want to explore or book a pass.
